{# Navegación "estilo wire:navigate": cada item swappea SOLO #tt-admin-content (morph), nunca el sidebar ni el → el menú queda quieto, sin parpadeo, y funciona igual embebido en iframe. El activo se actualiza por JS (ttSetActive). El swap es `morph:outerHTML`, NO `innerHTML`: `hx-select` conserva el elemento coincidente (no sus hijos), así que el nodo recortado trae el mismo id que el destino.
